# AI Task Management Platform
Django DRF · React Vite · Celery + Redis · PostgreSQL

## Scope rules (CRITICAL)
- Backend task → read `.claude/skills/backend.md` · touch `backend/` only
- Frontend task → read `.claude/skills/frontend.md` · touch `frontend/` only
- Never touch both in the same task — stop and tell the user to split the task
- Do ONE thing per response: one file, one function, one fix — ask before doing more
- If a task feels large, break it down and confirm the first step before proceeding
